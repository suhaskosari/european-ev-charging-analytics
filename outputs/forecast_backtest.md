## Reading the result

- Best model by WAPE: **holt_winters_damped** (27.9%). The Holt-Winters model used in `forecasting.py` scores 27.9% (seasonal-naive: 38.8%).
- Daily sessions per city are small counts (about 8 per day), so Poisson noise sets a floor on achievable error; the WAPE here is dominated by irreducible randomness, not model weakness. The earlier claim that forecasts 'track actuals within ~5-8%' compared 30-day *averages*, which hides day-level error and is not a forecast-accuracy measure.
- Weather is not used as an input. A model with forecast temperature could do better in cold spells, but would need weather *forecasts* at prediction time, which this dataset does not contain.
- Intervals are not evaluated here; point forecasts only.
